With cross-entropy, a confident wrong answer (p near 0 for the true class) costs almost without limit: −log(0.01) = 4.6, −log(0.001) = 6.9. Squared error caps every example at 1, so it shrugs at the very mistakes you most want fixed.

Station 4 · Backpropagation

Blame flows backwards, one link at a time

Station 3 needed the slope. Here is where it comes from. The neuron is split into tiny steps, each one a block. Run forward to compute the loss. Then run backward: each block asks "if I nudged this, how much would the loss move?" and passes the answer to the blocks that fed it. Every rule is a one-line fact from school calculus. Yellow towers are the answers.

Station 9 · Convolution

      
One tiny neuron, slid across the whole image

      
For a real 64 × 64 colour face, a full layer that looks at every pixel at once needs millions of weights. A convolution uses one small 3 × 3 neuron and slides it to every position, writing its answer into a new grid. Same weights everywhere, so an eye detector works wherever the eye is. This is the layer the Colab notebook uses on CelebA.

Before you start

    
Why the books have so many equations

    
An equation is a sentence squeezed down. z = w·x + b means "multiply each input by how much it matters, add them up, then add a nudge." The books aren't writing garbage. They are writing three kinds of thing, and you only need the first kind to build:

    

      
Recipe
What to compute. There are about six of these, listed below. Everything in Murphy 1, D2L and most of Murphy 2 is these six, combined, plus one new idea (probability distributions over the knobs themselves).

      
Bookkeeping
The same recipe written for every index, layer and batch: Σ over i, superscripts for layer ℓ, matrices instead of loops. It looks like new math, but it's the same recipe written for every case at once.

      
Proof
Why the recipe works or when it fails. "Squared error = assume Gaussian noise" (Murphy §4.2). "A linear autoencoder = PCA" (§20.3.1). You can skip these on the first pass and come back once the simulation has made you ask "but why?"

    

    
So the order here is: see it move, run the code, then read the equation as a caption. Every station has an equation you can tap symbol by symbol.
